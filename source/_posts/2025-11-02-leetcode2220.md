**Problem:** [Minimum Bit Flips to Convert Number](https://leetcode.com/problems/minimum-bit-flips-to-convert-number/description/)

## 🧠 Approach

The solution is pretty much self explanatory.

## ⏱️ Complexity

_O(n)_ because there is only for-loop.

## ⏱️ Complexity

|          | Time   | Space  |
| -------- | ------ | ------ |
| Solution | _O(n)_ | _O(1)_ |

## ✅ Code (Python)

```python
class Solution:
    def minBitFlips(self, start: int, goal: int) -> int:
        # Get the binary representations of start and goal
        bin_start = bin(start)[2:]
        bin_goal = bin(goal)[2:]

        # Make sure the length are equal
        if len(bin_goal) > len(bin_start):
            bin_start = "0" * (len(bin_goal) - len(bin_start)) + bin_start
        elif len(bin_goal) < len(bin_start):
            bin_goal = "0" * (len(bin_start) - len(bin_goal)) + bin_goal

        # Iterate through to find the number of differences
        res = 0
        for i in range(len(bin_start)):
            if bin_start[i] != bin_goal[i]:
                res += 1

        return res
```
