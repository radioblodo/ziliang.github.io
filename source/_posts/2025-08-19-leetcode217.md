**Problem:** [Contains Duplicate](https://leetcode.cn/problems/contains-duplicate/description/)  
**Difficulty:** Easy

---

## 🧠 Approach

Firstly, we create a new HashSet object. HashSet doesn't allow duplicate items in it. Then using a for-loop, we add all the items in the nums array into the HashSet. Finally, we check if the size of the HashSet is equal to the length of the nums. If they are equal, it means there is no duplicate, we return false. Else, we return true. 

---

## ⏱️ Complexity

|          | Time   | Space  |
| -------- | ------ | ------ |
| Solution | _O(n)_ | _O(n)_ |

---

## ✅ Code (Java)

```java
class solution {
    public boolean containsDuplicate(int[] nums){
        Set<Integer> numsSet = new HashSet<>(); 

        for (int i = 0; i < nums.length; i++){
            numsSet.add(nums[i]);
        }

        if (numsSet.size() != nums.length){
            return true; 
        }

        return false; 
    }
}
```
