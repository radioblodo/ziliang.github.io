**Problem:** [Merge Intervals](https://leetcode.com/problems/merge-intervals/description/)  
**Difficulty:** Medium

---

## 🧠 Approach

The approach is simple. We have to sort `intervals` based on the first value. To do this, we can use the lambda function in either `sorted()` or `sort()`. In terms of space efficiency, it would be better to use `sort()` since it is in-place sorting. After we have sorted intervals, we can use 2 pointers to point to 2 intervals and use a helper function to check if the one on the right overlaps with the one on the left, for example, `[1,2]`, `[2,3]`, if it does, we simple change the last value of the interval on the left to the last value of the interval on the right. In the case that the last value of the interval on the left is larger than the last value of the interval on the right, we simply pop off the interval on the right and **not** increase our right pointer. In other cases, we increase both our left and right pointers.

---

## ⏱️ Complexity

|          | Time    | Space  |
| -------- | ------- | ------ |
| Solution | _O(nm)_ | _O(1)_ |

We have O(nm) for the time complexity because we have a while-loop through the n number of intervals and in the helper function, we potentially have to compare m number of elements in the interval on the right and hence that would be O(nm). As for space, we didn't have to use any extra space since it was in-place sorting, hence it will be O(1).

## ✅ Code (Python)

```python
class Solution:
    def isOverlap(self, intervalOne: List[int], intervalTwo: List[int]):
        for number in range(intervalOne[0], intervalOne[1]+1):
            if number in list(range(intervalTwo[0], intervalTwo[1]+1)):
                return True

        return False

    def merge(self, intervals: List[List[int]]) -> List[List[int]]:
        if len(intervals) == 1:
            return intervals

        intervals.sort(key=lambda x: x[0])
        # left pointer
        left = 0
        # right pointer
        right = 1

        while right < len(intervals):
            if self.isOverlap(intervals[right], intervals[left]):
                if (intervals[left][1] < intervals[right][1]):
                    intervals[left][1] = intervals[right][1]
                intervals.pop(right)
            else:
                left += 1
                right += 1

        return intervals
```
