**Problem:** [Valid Palindrome](https://leetcode.cn/problems/valid-palindrome/description/)  
**Difficulty:** Easy
---

## 🧠 Approach

String in Java is immutable, but we can modify and reassign it to the same variable. We first make the spaces be removed by using `.replace(" ", "")`. Then, we convert all characters into lower case. Then we assign a left and a right pointer and iterate through from both ends to check if the characters equal, skipping non-alphanumeric characters along the way by using `Character.isLetterOrDigit()`

---

## ⏱️ Complexity

|          | Time   | Space  |
| -------- | ------ | ------ |
| Solution | _O(n)_ | _O(n)_ |

---

## ✅ Code (Java)

```java
class Solution {
    public boolean isPalindrome(String s) {
        s = s.replace(" ", "");
        s = s.toLowerCase(); 
        char[] ca = s.toCharArray(); 
        int left = 0; 
        int right = s.length - 1; 
        while (right > left){
            if (!Character.isLetterOrDigit(ca[left])){
                left += 1; 
                continue; 
            }
            if (!Character.isLetterOrDigit(ca[right])){
                right -= 1;  
                continue; 
            }
            if (!(ca[left]==ca[right])){
                return false; 
            }
        }
        return true; 
    }
}
```
