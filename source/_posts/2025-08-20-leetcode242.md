**Problem:** [Valid Anagram](https://leetcode.cn/problems/valid-anagram/description/)  
**Difficulty:** Easy

---

## 🧠 Approach

We simply need to have a counter for each unique character and compare the 2 counters. 

---

## ⏱️ Complexity

|          | Time   | Space  |
| -------- | ------ | ------ |
| Solution | _O(n)_ | _O(n)_ |

---

## ✅ Code (Java)

```java
class Solution {
    public boolean isAnagram(String s, String t) {
        Map<Character, Integer> counterS = new HashMap<>(); 
        for (char c : s.toCharArray()){
            counterS.put(c, counterS.getOrDefault(c, 0) + 1);
        }
        Map<Character, Integer> counterT = new HashMap<>(); 
        for (char c : t.toCharArray()){
            counterT.put(c, counterT.getOrDefault(c, 0) + 1);
        }
        if (counterS.size() != counterT.size()){
            return false; 
        }
        for (char key : counterS.keySet()){
            if (!Object.equals(counterS.get(key), counterT.get(key))){
                return false; 
            }
        }
        return true; 
}
```
