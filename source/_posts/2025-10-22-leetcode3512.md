**Problem:** [Minimum Operations to Make Array Sum Divisible by K](https://leetcode.com/problems/buy-two-chocolates/description/)  
**Difficulty:** Easy

---

## 🧠 Approach

We simply have to find the remainder if we take the sum and modulo it with k, that will be the number of subtraction operations we have to perform to get to a number that is wholly divisible by k.

---

## ⏱️ Complexity

|          | Time   | Space  |
| -------- | ------ | ------ |
| Solution | _O(1)_ | _O(1)_ |

Modulo is _O(1)_. We did not use extra space either.

## ✅ Code (Python)

```python
class Solution:
    def minOperations(self, nums: List[int], k: int) -> int:
        return sum(nums) % k
```
