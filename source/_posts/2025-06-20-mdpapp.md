As part of NTU’s **Multidisciplinary Design Project (MDP)** — a capstone module for final-year Computer Science students — my team developed a mobile-controlled robot capable of both autonomous and manual navigation.

**Core components**

- 📱 **Android App** (my main role)
- 🍓 **Raspberry Pi** (Bluetooth receiver + logic relay)
- 🧠 **Pathfinding Algorithm**
- 🔩 **STM32 Microcontroller** (motor control + sensors)

Although I owned the Android app, I also contributed to Raspberry Pi development, STM32 signal testing, and cross-team integration.

---

## 🎯 Project Goals

Built in **Kotlin** with **Jetpack Compose**, the app aimed to:

- Establish a reliable **Bluetooth connection** to the Raspberry Pi
- Provide **manual robot control** with directional buttons
- Display **live feedback** from the robot (status, position)
- Log the robot’s path for testing and visualization

---

## ⚙️ Key Technical Highlights

- Clean, responsive UI with **Jetpack Compose**
- **Bluetooth socket** communication with efficient I/O stream handling
- Smooth two-way messaging for **manual overrides**, **status polling**, and **sensor relay**
- **Live logs** and **status tracking** for debugging and verification

## 🧠 What I Learned

- Calling and parsing JSON between Android and hardware endpoints
- Working with **hardware protocols** (Raspberry Pi & STM32 over Bluetooth/serial)
- Debugging across platforms (Android logs, RPi console, STM32 UART)
- The value of **cross-functional collaboration** in embedded + mobile systems
