**Problem:** [Number of Subarrays That Match a Pattern I](https://leetcode.com/problems/number-of-subarrays-that-match-a-pattern-i/description/)  
**Difficulty:** Medium

---

## 🧠 Approach

This is the more intuitive solution where we keep a list of subarrays and simply use the pattern to check whether each subarray matches the requirements of the pattern.

---

## ⏱️ Complexity

|          | Time               | Space  |
| -------- | ------------------ | ------ |
| Solution | _O(n<sup>2</sup>)_ | _O(n)_ |

## ✅ Code (Python)

```python
class Solution:
    def countMatchingSubarrays(self, nums: List[int], pattern: List[int]) -> int:
        # Get the length of the pattern
        n = len(pattern)

        # Get the subarrays of length n + 1
        subarrays = list()
        for i in range(len(nums)-n):
            subarrays.append(nums[i:i+n+1])

        # Check each subarray
        count = 0
        flag = True
        for subarray in subarrays:
            flag = True
            for j in range(n):
                if pattern[j] == 1:
                    if subarray[j] < subarray[j+1]:
                        continue
                    else:
                        flag = False
                        break
                elif pattern[j] == 0:
                    if subarray[j] == subarray[j+1]:
                        continue
                    else:
                        flag = False
                        break
                else:
                    if subarray[j] > subarray[j+1]:
                        continue
                    else:
                        flag = False
                        break
            if flag:
                count += 1

        return count

```
