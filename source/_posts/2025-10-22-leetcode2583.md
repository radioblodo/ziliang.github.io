**Problem:** [Kth Largest Sum in a Binary Tree](https://leetcode.com/problems/kth-largest-sum-in-a-binary-tree/description/)  
**Difficulty:** Medium

---

## 🧠 Approach

This problem is about Breadth-First search to calculate the level sum for each level. The thing to remember is to use a for-loop to pop off each node in the current level. After we have obtained the level sum for each level, we can use the in-place sorting algorithm provided by Timsort again. Then we can simply return the value at len(level_sum) - k since that is the Kth largest level sum.

---

## ⏱️ Complexity

|          | Time   | Space  |
| -------- | ------ | ------ |
| Solution | _O(n)_ | _O(n)_ |

The time complexity of BFS algorithm on a binary tree is _O(n)_. As for space, we made use of extra space for the deque object to contain n number of nodes as well as the extra list to store the level*sum. That would be \_O(n)* as well.

## ✅ Code (Python)

```python
from collections import deque

# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def kthLargestLevelSum(self, root: Optional[TreeNode], k: int) -> int:
        # Create a deque object
        q = deque()

        # Enqueue the root node
        q.append([root, root.val])

        level_sum = []
        # Use a while-loop to perform bfs
        while q:
            current_sum = 0
            level_size = len(q)

            for i in range(level_size):
                node, value = q.popleft()
                current_sum += value
                if node.left:
                    q.append([node.left, node.left.val])
                if node.right:
                    q.append([node.right, node.right.val])

            level_sum.append(current_sum)

        # Sort the level sums in ascending order
        level_sum.sort()

        # Return the kth largest level sum by taking k-1
        if len(level_sum) < k:
            return -1

        return level_sum[len(level_sum) - k]




```
