**Problem:** [Power of Three](https://leetcode.cn/problems/power-of-three/description/?envType=daily-question&envId=2025-08-13)  
**Difficulty:** Easy

---

## 🧠 Approach

To determine if a number is a power of 3, we just need to use recursion to recursively divide n by 3. If it ever gets below 0 or if the modulo of n is ever not 0, then we can return false, else wait till 3/3 == 1, then we return true.

---

## ⏱️ Complexity

|          | Time                   | Space                  |
| -------- | ---------------------- | ---------------------- |
| Solution | _O(log<sub>3</sub> n)_ | _O(log<sub>3</sub> n)_ |

---

## ✅ Code (Java)

```java
class Solution {
    public boolean isPowerOfThree(int n) {
        if (n == 1) return true;   // 3^0 = 1
        if (n <= 0 || n % 3 != 0) return false;
        return isPowerOfThree(n / 3);
    }
}
```
