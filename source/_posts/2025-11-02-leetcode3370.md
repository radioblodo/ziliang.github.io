**Problem:** [Smallest Number With All Set Bits](https://leetcode.com/problems/smallest-number-with-all-set-bits/description/)  
**Difficulty:** Easy

---

## 🧠 Approach

This is a simple problem. We could either use a simple while-loop or recursion to do it.

---

## ⏱️ Complexity

_O(n logn)_ because bin() takes _O(logn)_ and it takes about _O(n)_ iterations to get to the next number with all set bits.

---

## ⏱️ Complexity

|          | Time       | Space     |
| -------- | ---------- | --------- |
| Solution | _O(nlogn)_ | _O(logn)_ |

## ✅ Code (Python)

### Solution 1: Iterative while-loop

```python
class Solution:
    def smallestNumber(self, n: int) -> int:
        while '0' in bin(n)[2:]:
            n += 1

        return n
```

### Solution 2: Recursive

```python
class Solution:
    def smallestNumber(self, n: int) -> int:
        return n if '0' not in bin(n)[2:] else self.smallestNumber(n+1)
```
