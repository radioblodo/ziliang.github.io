LeetCode 195 — Tenth Line

Problem: Tenth Line
Difficulty: Easy

🧠 Approach

This is an easy problem and the description is fairly short. I think it’s a either you know it or you don’t know it kind of question. I checked on ChatGPT for the bash command and there are actually several ways to print the line:

  • sed -n '10p' filename
  • awk 'NR==10' filename
  • head -n 10 filename | tail -n 1
  • line=$(sed -n '5p' filename) \n echo "$line"

⏱️ Complexity

Time Space
Solution O(n) O(1)

✅ Code (Bash)
