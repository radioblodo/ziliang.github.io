## ⏱️ Complexity

|          | Time    | Space  |
| -------- | ------- | ------ |
| Solution | _O(nm)_ | _O(1)_ |

We have O(nm) for the time complexity because we have a while-loop through the n number of intervals and in the helper function, we potentially have to compare m number of elements in the interval on the right and hence that would be O(nm). As for space, we didn't have to use any extra space since it was in-place sorting, hence it will be O(1).

## ✅ Code (Python)

```python
class Solution:
    def isOverlap(self, intervalOne: List[int], intervalTwo: List[int]):
        for number in range(intervalOne[0], intervalOne[1]+1):
            if number in list(range(intervalTwo[0], intervalTwo[1]+1)):
                return True

        return False

    def merge(self, intervals: List[List[int]]) -> List[List[int]]:
        if len(intervals) == 1:
            return intervals

        intervals.sort(key=lambda x: x[0])
        # left pointer
        left = 0
        # right pointer
        right = 1

        while right < len(intervals):
            if self.isOverlap(intervals[right], intervals[left]):
                if (intervals[left][1] < intervals[right][1]):
                    intervals[left][1] = intervals[right][1]
                intervals.pop(right)
            else:
                left += 1
                right += 1

        return intervals

    def insert(self, intervals: List[List[int]], newInterval: List[int]) -> List[List[int]]:
        # simply insert the new interval
        intervals.append(newInterval)

        # sort the intervals
        intervals.sort(key=lambda x:x[0])

        # use the merge intervals function
        return self.merge(intervals)

```
