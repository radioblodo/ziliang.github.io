**Problem:** [Number of Zero-Filled Subarrays](https://leetcode.cn/problems/number-of-zero-filled-subarrays/description/?envType=daily-question&envId=2025-08-19)  
**Difficulty:** Medium

---

## 🧠 Approach

This problem is quite clear, it wants us to return the number of ways we can form subarrays of 0, contiguous subarrays. The key is to understand the pattern.
Say we have [0,0,0],

- the number of ways to form subarray of [0] is 3,
- the number of ways to form subarray of [0,0] is 2
- the number of ways to form subarray of [0,0,0] is 1

Hence, from this, we can see that as we are iterating through [0,0,0], we can add 1 + 2 + 3, then reset when we find the next 0 and do the same. Finally, we return the sum of the number of ways.

---

## ⏱️ Complexity

|          | Time   | Space  |
| -------- | ------ | ------ |
| Solution | _O(n)_ | _O(1)_ |

---

## ✅ Code (Java)

```java
class Solution {
    public long zeroFilledSubarray(int[] nums) {
        long res = 0L;
        long run = 0L;

        for (int num : nums){
            if (num == 0){
                run += 1;
                res += run;
            }
            else{
                // need to reset
                run = 0L;
            }
        }

        return res;
    }
}
```
