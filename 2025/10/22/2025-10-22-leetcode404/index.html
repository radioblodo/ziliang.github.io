LeetCode 404 — Sum of Left Leaves

Problem: Sum of Left Leaves
Difficulty: Easy

🧠 Approach

This is a simple one pass solution. No extra space is required. Something I learned from this problem is that in order for the inner function to be able to modify the value of a variable that was defined in the outer function, there needs to be a nonlocal variable_name declaration in the inner function, else the inner function only has the read access but not write access.

⏱️ Complexity

Time Space
Solution O(n) O(1)

The time complexity of Depth-First Search (DFS) on a binary tree is O(n), where n is the number of nodes in the tree. O(1) for space since no extra space is required.
