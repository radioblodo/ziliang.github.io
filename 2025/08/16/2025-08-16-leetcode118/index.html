LeetCode 118 — Pascal's Triangle

Problem: Pascal’s Triangle
Difficulty: Easy

🧠 Approach

The objective of this problem is fairly straightforward, construct a Pascal Triangle of the given number of rows. However, looking at the hints, we know this would involve dynamic programming. The key is then to figure out the repetitve parts since dynamic programming is all about finding the repeating part. We notice that for each row, the first and last element are always 1. The elements in between, are the sum of element in the previous row and previous column and the element in the previous row and the same column. Hence, this is the repeating part.

To solve it, we can:

  1. For each row, create a new ArrayList
  2. If the position is 0 or the last element, we populate it with 1
  3. If the position is not 0 or the last element, we populate it with pascalTriangle.get(row-1).get(col-1) + pascalTriangle.get(row-1).get(col)

⏱️ Complexity

Time Space
Solution O(n2) O(n2)
