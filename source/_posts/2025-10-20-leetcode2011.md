## 🧠 Approach

This is a simple one pass solution. No extra space is required.

---

## ⏱️ Complexity

|          | Time   | Space  |
| -------- | ------ | ------ |
| Solution | _O(n)_ | _O(1)_ |

Only 1 for-loop hence O(n). O(1) for space since no extra space is required.

## ✅ Code (Python)

```python
class Solution:
    def finalValueAfterOperations(self, operations: List[str]) -> int:
        res = 0
        for op in operations:
            if op == "X++" or op == "++X":
                res += 1
            else:
                res -=1

        return res

```
