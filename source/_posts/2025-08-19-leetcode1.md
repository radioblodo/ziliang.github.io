**Problem:** [Two Sum](https://leetcode.cn/problems/two-sum/description/)  
**Difficulty:** Easy

---

## 🧠 Approach

Firstly, we need to create a HashMap object to map the value to the index. The reason why we are mapping value->index is because it takes O(1) to access the value, hence it will be faster to check if the complement exists in the HashMap later on. If the complement does not exist, we put the current value->index mapping into the HashMap first. When we eventually reach the complement, the complement of the complement would have already been added to the HashMap, that's when we can return the array of the 2 indexes. In short, to break down into baby steps:

- Create a HashMap object
- Iterate through nums
- Check if the complement is already in the HashMap
-   If not, add the current value->index into the HashMap
-   If yes, add the current index, HashMap.get(value) into an array and return it

---

## ⏱️ Complexity

|          | Time   | Space  |
| -------- | ------ | ------ |
| Solution | _O(n)_ | _O(n)_ |

---

## ✅ Code (Java)

```java
class solution {
    public int twoSum(int[] nums, int target){
        Map<Integer, Integer> hashmap = new HashMap<>(); 

        for (int i = 0; i < nums.length; i++){
            if (hashmap.containsKey(target-nums[i])){
                return new int[]{i, hashmap.get(target-nums[i])};
            }
            hashmap.put(nums[i], i);
        }

        return new int[2];
    }
}
```
