**Problem:** [Delete Nodes From Linked List Present in Array](https://leetcode.com/problems/delete-nodes-from-linked-list-present-in-array/description/)  
**Difficulty:** Medium

---

## 🧠 Approach

The solution is pretty much self explanatory.

## ⏱️ Complexity

_O(n<sup>2</sup>)_ due to the nested while-loop.

---

## ⏱️ Complexity

|          | Time               | Space  |
| -------- | ------------------ | ------ |
| Solution | _O(n<sup>2</sup>)_ | _O(1)_ |

## ✅ Code (Python)

```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
class Solution:
    def modifiedList(self, nums: List[int], head: Optional[ListNode]) -> Optional[ListNode]:
        if head == None:
            return None

        if len(nums) == 0:
            return head

        nums = set(nums)

        dummy = head

        while dummy.val in nums:
            dummy = dummy.next

        new_head = dummy
        dummy = dummy.next
        cur = new_head

        while dummy != None:
            while dummy != None and dummy.val in nums:
                dummy = dummy.next

            cur.next = dummy
            cur = cur.next
            if dummy:
                dummy = dummy.next

        return new_head
```
