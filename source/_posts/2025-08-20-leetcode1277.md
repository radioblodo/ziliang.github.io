**Problem:** [Count Square Submatrices with All Ones](https://leetcode.cn/problems/count-square-submatrices-with-all-ones/description/?envType=daily-question&envId=2025-08-20)  
**Difficulty:** Medium
---

## 🧠 Approach

This problem involves dynamic programming. We can build a 2D dp array of the same dimension as the matrix passed in. Then we fill in the first row and first column. Whenever there is 1, we add 1 to the result. Once we move inwards to the second row and second column, the largest square that can be formed will depend on the smallest value of the left, top and topleft corner of the current cell. That will be the value in the current cell. In the end, we simply have to sum up all the values in the dp array and return it. 

---

## ⏱️ Complexity

|          | Time   | Space  |
| -------- | ------ | ------ |
| Solution | _O(n<sup>2</sup>)_ | _O(n)_ |

## ✅ Code (Java)

```java
class Solution {
    public int countSquares(int[][] matrix) {
        int[][] dp = new int[matrix.length][matrix[0].length];
        int total = 0;
        // Initialize dp array and count for the first row and column
        for (int r = 0; r < matrix.length; r++) {
            dp[r][0] = matrix[r][0];
            total += dp[r][0];
        }
        for (int c = 1; c < matrix[0].length; c++) {
            dp[0][c] = matrix[0][c];
            total += dp[0][c];
        }

        for (int r = 1; r < matrix.length; r++){
            for (int c = 1; c < matrix[0].length; c++){
                if (matrix[r][c] == 0){
                    dp[r][c] = 0;
                }
                else{
                    dp[r][c] = Math.min(dp[r][c-1], Math.min(dp[r-1][c], dp[r-1][c-1]))+1;
                }
            }
        }

        
        for (int r = 1; r < dp.length; r++){
            for (int c = 1; c < dp[0].length; c++){
                total += dp[r][c];
            }
        }
        
        return total; 
    }
}
```
