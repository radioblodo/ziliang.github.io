**Problem:** [Number of Laser Beams in a Bank](https://leetcode.com/problems/number-of-laser-beams-in-a-bank/description/)  
**Difficulty:** Medium

---

## 🧠 Approach

The idea is simple, we multiply the number of beams in the previous row that has beams with the number of beams in the row that has beams. Then we sum them up and return.

---

## ⏱️ Complexity

We are only iterating through the `bank` array once. For space complexity, we did not create any new variable apart from the `prev` and `res` which are constant.

---

## ⏱️ Complexity

|          | Time   | Space  |
| -------- | ------ | ------ |
| Solution | _O(n)_ | _O(1)_ |

## ✅ Code (Python)

```python
class Solution:
    def numberOfBeams(self, bank: List[str]) -> int:
        prev = 0
        res = 0
        for row in bank:
            if '1' not in row:
                continue
            cur = row.count('1')
            res += prev * cur
            prev = cur

        return res
```
