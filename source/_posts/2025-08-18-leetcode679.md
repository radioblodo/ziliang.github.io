**Problem:** [24 Game](https://leetcode.cn/problems/24-game/description/?envType=daily-question&envId=2025-08-18)  
**Difficulty:** Hard

## 🧠 Approach

This is quite a challenging problem because I always struggle in visualising the recursion pattern. Although from the tag, we can tell that this is a recursion problem. I didn't immediately realised how to do this. But here is a picture that illustrates the recursion. 

![24 Game Recursion Tree](/img/24game.png)

Basically, the idea is that from the original 4 numbers, we select 2 numbers out and perform the 6 possible operations between the 2 numbers. Which 6?
- a + b
- a - b
- b - a
- a * b
- a / b
- b / a

Then, we add the result that we obtain from the said operation back to the array, and again repeat the process mentioned above, choose 2 numbers out, perform the 6 possible operations, until finally, we are left with 1 number, which is also the exit condition of this recursion. Atlas, we check using Math.abs(nums.get(0)-24) < EPS to see whether it is indeed 24. Why do we check whether it is smaller than EPS you ask? Well I asked ChatGPT too haha. Reason is because in certain operations, like 1/3, in Java and Python, this is only stored approximately. When you combine these approximations with other operations, the final result might be 23.9999998 or 24.0000001, not exactly 24.0. This might cause us to wrongly conclude that there is no solution that can result in 24, hence we compare with 1e−6.

## ✅ Code (Java)

```java
class Solution {
    private static final double EPS = 1e-6; 

    public boolean judgePoint24(int[] cards) {
        // convert the integer into double
        List<Double> nums = new ArrayList<>(4);
        for (int x : cards){
            nums.add((double) x);
        }
        return dfs(nums); 
    }

    public boolean dfs(List<Double> nums){
        if (nums.size() == 1){
            return Math.abs(nums.get(0) - 24) < EPS;
        }

        int n = nums.size(); 
        for (int i = 0; i < n; i++){
            for (int j = 0; j < n; j++){
                if (i == j){
                    continue;
                }
                double a = nums.get(i);
                double b = nums.get(j); 

                List<Double> next = new ArrayList<>(n-1);
                for (int k = 0; k < n; k++){
                    if (k!=i && k!=j){
                        next.add(nums.get(k));
                    }
                }

                double [] candidates = {
                    a + b,
                    a - b,
                    b - a, 
                    a * b,
                    (Math.abs(b) > EPS) ? (a/b) : Double.NaN,
                    (Math.abs(a) > EPS) ? (b/a) : Double.NaN
                };

                for (double r : candidates){
                    if (Double.isNaN(r)){
                        continue;
                    }
                    next.add(r);
                    if (dfs(next)){
                        return true;
                    }
                    next.remove(next.size()-1);
                }
            }
        }

        return false;
    }
}
```
