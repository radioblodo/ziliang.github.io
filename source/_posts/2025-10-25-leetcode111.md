**Problem:** [Tree, Depth-First Search, Breadth-First Search, Binary Tree](https://leetcode.com/problems/minimum-depth-of-binary-tree/description/)  
**Difficulty:** Easy

---

## 🧠 Approach

We just need to use BFS. As soon as we found a leaf node, a node with no left and right child nodes, that means we have reached the leaf node and we can return the depth at that level.

---

## ⏱️ Complexity

Time Complexity: O(n)

Each node in the tree is visited exactly once. The operations within the loop (append, popleft) for the deque are O(1). For n nodes, we perform O(1) work for each node

Space Complexity: O(w)

Where w is the maximum width of the binary tree. The queue will store at most w nodes at any given time. In the worst case (complete binary tree), the maximum width could be n/2, making it O(n). The result list res stores all n values but this is considered output space

---

## ⏱️ Complexity

|          | Time   | Space  |
| -------- | ------ | ------ |
| Solution | _O(n)_ | _O(n)_ |

## ✅ Code (Python)

```python
from collections import deque

# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def minDepth(self, root: Optional[TreeNode]) -> int:
        if root == None:
            return 0

        minDepth = 1

        # Create a deque object
        q = deque()

        # Put the root node into the deque
        q.append(root)

        while(q):
            n = len(q)
            for i in range(n):
                node = q.popleft()
                if node.left == None and node.right == None:
                    return minDepth

                if node.left:
                    q.append(node.left)
                if node.right:
                    q.append(node.right)
            minDepth += 1

        return minDepth
```
