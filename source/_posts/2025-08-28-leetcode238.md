**Problem:** [Product of Array Except Self](https://leetcode.cn/problems/product-of-array-except-self/description/)  
**Difficulty:** Medium

---

## 🧠 Approach

To not create extra arrays, we need to create only 1 array of size n, where n is the length of the given array.

Then create a dummy 1 on the left and populate the left pass first, where i = 1 to i < n is filled with res[i-1] \* nums[i-1]

Then we do a right pass with a dummy r = 1 and res[i] = res[i] \* r and r is increasinly multiplied by nums[i]

---

## ⏱️ Complexity

|          | Time   | Space  |
| -------- | ------ | ------ |
| Solution | _O(n)_ | _O(n)_ |

---

## ✅ Code (Java)

```java
class Solution {
    public int[] productExceptSelf(int[] nums) {
        int n = nums.length;
        int[] res = new int[n];

        res[0] = 1;
        for (int i = 1; i < n; i++){
            res[i] = res[i-1] * nums[i-1];
        }

        int r = 1;
        for (int i = n - 1; i >= 0; i--){
            res[i] = res[i] * r;
            r *= nums[i];
        }

        return res;
    }
}
```
