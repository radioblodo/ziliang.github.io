**Problem:** [Group Anagrams](https://leetcode.cn/problems/group-anagrams/description/)  
**Difficulty:** Medium

---

## 🧠 Approach

This is doable if you choose the right approach. Initially, I used the Counter approach to count the occurrences of each letter in each string in the given List. However, that soon exceeded the time limit. The faster way would be to create a Map of sorted string (key) to a list of strings that which sorted, will be the key. For example:

- eat, tea, ate (These strings all belong to the same group.)

1. We first sort it into aet (alphabetical order).
2. We check if the list is null, if it is, create a new list and add all the strings that have the same key.
3. Return the values of the Map.

---

## ⏱️ Complexity

|          | Time             | Space      |
| -------- | ---------------- | ---------- |
| Solution | _O(n · k log k)_ | _O(n · k)_ |

---

## ✅ Code (Java)

```java
class Solution {
    public List<List<String>> groupAnagrams(String[] strs) {
        Map<String, List<String>> groups = new HashMap<>();

        for (String str : strs){
            char[] ca = str.toCharArray();
            Arrays.sort(ca);
            String key = new String(ca);

            list = groups.get(key);
            if (list == null){
                list = new ArrayList<String>();
                groups.put(key, list);
            }
            list.add(str);
        }

        return new ArrayList<>(groups.values());
    }
}
```
