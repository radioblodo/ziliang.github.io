**Problem:** [Maximum Number of Distinct Elements After Operations](https://leetcode.com/problems/maximum-number-of-distinct-elements-after-operations/description/?envType=daily-question&envId=2025-10-18)  
**Difficulty:** Medium

---

## 🧠 Approach

We need to sort the numbers in ascending order so that we can always pick the leftmost unused number in the range. The overall range for the input array `[a...b]` is `[a-k...b+k]`. For repeated numbers, since they are sorted, for example, `[4,4,4,4,5]`, we can keep track of the already 'taken' number by using the `max_number` we have seen so far.

For example, `[4,4,4,4,5]` and `k=2`.
The left will be 4 - 2 = 2 and the right will be 4 + 2 = 6
The first distinct element will be max(-inf, 2), which will be 2.
`[2]`
We have seen 2, so the next free would be 3.  
The second distinct element will be max(3, 2) since the left remains at 4 - 2 = 2.
`[2,3]`
We have seen 3, so the next free would be 4.
The third distinct element we have will be max(4, 2) since the left remains at 4 - 2 = 2
`[2,3,4]`
We have seen 4, so the next free would be 5.
The fourth distinct element will be max(5, 2) since the left remains at 4 - 2 = 2
`[2,3,4,5]`
We have seen 5, so the next free would be 6.
The fifth distinct element will be max(6, 3) because the left got updated to 5 - 2 = 3.
The thing to note is that for the input number 5, it could be mapped to any number [3,7] but because 6 was not yet mapped to by the 4 previously, 6 will be allocated to be mapped to by 5. This is the greediness part of this algorithm.
The final output array will be `[2,3,4,5,6]`. Hence, the maximum number of distinct elements will be 5.

---

## ⏱️ Complexity

|          | Time       | Space  |
| -------- | ---------- | ------ |
| Solution | _O(nlogn)_ | _O(1)_ |

We have O(nlogn) for the time complexity of performing sorting when we use Timsort in-place sorting algorithm. As for space, we didn't have to use any extra space since it was in-place sorting, hence it will be O(1).

## ✅ Code (Python)

```python
class Solution:
    def maxDistinctElements(self, nums: List[int], k: int) -> int:
        nums.sort()
        next_free = float('-inf')
        count = 0
        for n in nums:
            left = n - k
            right = n + k
            x = max(next_free, left)
            if x <= right:
                count += 1
                next_free = x + 1
        return count
```
