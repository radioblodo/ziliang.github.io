## 🧠 Approach

We use a sliding window technique to check if the adjacent array is also increasing. The start index of the adjacent array will therefore be at `i + k`. If both flags are `True`, we return True.

---

## ⏱️ Complexity

Time Complexity: _O(n<sup>2</sup>)_

We have a nested for-loop hence the overall time complexity would be _O(n<sup>2</sup>)_.

Space Complexity: _O(1)_

Only two boolean variables are created and they are constant space, so _O(1)_.

---

## ⏱️ Complexity

|          | Time   | Space  |
| -------- | ------ | ------ |
| Solution | _O(n)_ | _O(1)_ |

## ✅ Code (Python)

```python
class Solution:
    def hasIncreasingSubarrays(self, nums: List[int], k: int) -> bool:
        # Use a sliding window
        flagOne = True # assume first subarray is strictly increasing
        flagTwo = True # assume second subarray is strictly increasing
        for i in range(len(nums)-2*k+1):
            flagOne = True
            flagTwo = True
            # Check the left subarray if it is increasing
            for j in range(i, i+k-1,1):
                if nums[j] < nums[j+1]:
                    continue
                else:
                    flagOne = False
                    break

            if flagOne:
                for m in range(i+k, i+k+k-1, 1):
                    if nums[m] < nums[m+1]:
                        continue
                    else:
                        flagTwo = False
                        break

            if flagOne and flagTwo:
                return True

        return False
```
