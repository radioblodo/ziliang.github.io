**Problem:** [The Two Sneaky Numbers of Digitville](https://leetcode.com/problems/the-two-sneaky-numbers-of-digitville/description/)  
**Difficulty:** Easy

---

## 🧠 Approach

This is a very simple problem. We sort and then add in the numbers whenever there are same number side by side.

## ⏱️ Complexity

_O(n)_ because there is only 1 for-loop. _O(1)_ because res only has 2 elements.

---

## ⏱️ Complexity

|          | Time   | Space  |
| -------- | ------ | ------ |
| Solution | _O(n)_ | _O(1)_ |

## ✅ Code (Python)

```python
class Solution:
    def getSneakyNumbers(self, nums: List[int]) -> List[int]:
        # Sort the given nums array in O(n log n)
        nums.sort()

        # Iterate through the array to get the duplicates
        res = []
        for i in range(len(nums)-1):
            if nums[i] == nums[i+1]:
                res.append(nums[i])

        return res
```
