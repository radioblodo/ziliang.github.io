**Problem:** [Convert Sorted Array into Binary Search Tree](https://leetcode.cn/problems/convert-sorted-array-to-binary-search-tree/description/?envType=study-plan-v2&envId=top-interview-150)  
**Difficulty:** Easy

---

## 🧠 Approach

Since the list is sorted, we have to recursively pick the smaller number from the left and the bigger number from the right. 

---

## ⏱️ Complexity

|          | Time                   | Space                  |
| -------- | ---------------------- | ---------------------- |
| Solution | _O(n<sup>2</sup>)_ | _O(n)_ |

---

## ✅ Code (Java)

```java
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    public TreeNode sortedArrayToBST(int[] nums) {
        return buildTree(nums, 0, nums.length - 1); 
    }

    public TreeNode buildTree(int[] a, int low, int high){
        if(low > high){
            return null;
        }
        int mid = low + (high - low) / 2; 
        TreeNode root = new TreeNode(a[mid]); 
        root.left = buildTree(a, low, mid -1);
        root.right = buildTree(a, mid + 1, high);
        return root; 
    }
}
```
