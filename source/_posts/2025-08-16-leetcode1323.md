**Problem:** [Maximum 69 Number](https://leetcode.cn/problems/maximum-69-number/description/?envType=daily-question&envId=2025-08-16)  
**Difficulty:** Easy

---

## 🧠 Approach

This problem is fairly simple, we just need to find the first occurrence of '6' from the left and change it to 9. In case we cannot find, we simply return the given number. Hence, knowing this, we can break this down into 2 sub-problems:

1. Convert the given number to String
2. Iterate through the string to find the first '6' char

I am sure this is not the most elegant or the most efficient solution but I believe this is the most intuitive way of looking at the problem.

---

## ⏱️ Complexity

|          | Time   | Space  |
| -------- | ------ | ------ |
| Solution | _O(n)_ | _O(n)_ |

---

## ✅ Code (Java)

```java
class Solution {
    public int maximum69Number (int num) {
        // Convert the given number to string
        String numString = Integer.toString(num);
        // Find the first occurrence of 6, counting from the left
        Integer indexToChange = null;
        for (int i = 0; i < numString.length(); i++){
            if (numString.charAt(i) == '6'){
                indexToChange = i;
                break;
            }
        }
        if (indexToChange == null){
            return num;
        }
        StringBuilder sb = new StringBuilder(numString);
        sb.setCharAt(indexToChange, '9');
        String newString = sb.toString();

        return Integer.parseInt(newString);
    }
}
```
