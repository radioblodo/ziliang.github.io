**Problem:** [Remove Zeros in Decimal Representation](https://leetcode.com/problems/remove-zeros-in-decimal-representation/description/)  
**Difficulty:** Easy

---

## 🧠 Approach

This is a very straightforward question. We just need to convert it into a string representation, then iterate through the characters of the string and concatenate the empty string whenever the character is non-zero.

---

## ⏱️ Complexity

Time Complexity: _O(n<sup>2</sup>)_

1 for-loop, but strings in Python are immutable hence everytime we concatenate, what is happening under the hood is actually Python creates a new string, copies all existing characters from the old string, adds the new character, thus resulting in _O(n<sup>2</sup>)_. This copying gets more expensive as the string grows and that is why this solution is actually not the ideal solution.

Space Complexity: _O(n)_

---

## ⏱️ Complexity

|          | Time               | Space  |
| -------- | ------------------ | ------ |
| Solution | _O(n<sup>2</sup>)_ | _O(n)_ |

## ✅ Code (Python)

### 🟩 Solution 1: String Filtering Approach

```python
class Solution:
    def removeZeros(self, n: int) -> int:
        # Convert to string representation
        s = str(n)

        # Create a res to concatenate without the 0s
        res = ""
        for char in s:
            if char != '0':
                res += char

        return int(res)
```

### 🟩 Solution 2: Using List Comprehension

```python
class Solution:
    def removeZeros(self, n: int) -> int:
        chars = []
        for char in str(n):
            if char != '0':
                chars.append(char)

        return int(''.join(chars))
```

### 🟩 Solution 3: Using String Method: replace()

```python
class Solution:
    def removeZeros(self, n: int) -> int:
        int(str(n).replace('0', ''))
```
