**Problem:** [New 21 Game](https://leetcode.cn/problems/new-21-game/description/?envType=daily-question&envId=2025-08-17)  
**Difficulty:** Medium

---

## 🧠 Approach

Although this problem is labelled as Medium difficulty, I think it should be classified as Hard. I had a really difficult time trying to understand the concept and admittedly used ChatGPT to visualise the pattern. A few things that are intuitive:
- The probability from k to n(inclusive) is 1.0. Why? Because once you reach k or accidentally overshot k but still below or equal to n, the game terminates, hence the probability of that being n (which is what the question wants) is 1.0.
- The probability of n+1 to maxPts is 0.0. Rather, this part is not relevant to the probability that we are looking for (which is the probability of the final score being smaller than n). 
- We need to compute `dp[x]` for all `x < k`.  
The recurrence is: dp[x] = (dp[x+1] + dp[x+2] + ... + dp[x+maxPts]) / maxPts
- Lastly, we return the value of dp[0]
---

## ⏱️ Complexity

|          | Time                   | Space                  |
| -------- | ---------------------- | ---------------------- |
| Solution | _O(n+MaxPts)_ | _O(n+MaxPts)_ |

---

## ✅ Code (Java)

```java
class Solution {
    public double new21Game(int n, int k, int maxPts) {
        // Initialise the array of n + maxPts + 1 
        // Here we use double because we are storing probabilities
        double [] dp = new double[n+maxPts+1]; 

        // Fill base cases for x >= k 
        for (int i = k; i <= n; i++){
            dp[i] = 1.0;
        }
        for (int i = n+1; i <= n+maxPts ; i++){
            dp[i] = 0.0;
        }
        double windowSum = 0.0;
        for (int i = k; i < k + maxPts; i++){
            windowSum += dp[i]; 
        }
        for (int i = k-1; i >= 0; i--){ 
            dp[i] = windowSum/maxPts;  
            windowSum += dp[i] - dp[i+maxPts];
        }

        // Return the final result 
        return dp[0]; 
    }
}
```
