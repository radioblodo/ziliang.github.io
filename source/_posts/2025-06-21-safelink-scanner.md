# SafeLink Scanner – A Flutter App to Detect Malicious URLs

<div class="markdown-body">

🚫 The internet is filled with shortened URLs, suspicious links, and
phishing traps. I built **SafeLink Scanner**, a Flutter app that helps
users **check if a link is safe before opening it**.

------------------------------------------------------------------------

## <a href="#🔍-What-the-App-Does" class="headerlink"
title="🔍 What the App Does"></a>🔍 What the App Does

SafeLink Scanner lets users:

- Paste or share a link from another app
- Automatically check the URL against known threat databases like:
  - 🛡️ <a href="https://urlhaus.abuse.ch/" target="_blank"
    rel="noopener">URLHaus</a>
  - 🔎 <a href="https://urlscan.io/" target="_blank"
    rel="noopener">urlscan.io</a>
- View a clear warning or green-light based on results
- See a visual preview or breakdown of the destination site

The goal is to **reduce accidental link clicks** on phishing pages or
malware payloads.

------------------------------------------------------------------------

## <a href="#🧰-Tech-Stack" class="headerlink" title="🧰 Tech Stack"></a>🧰 Tech Stack

| Layer        | Tools & Tech                                      |
|--------------|---------------------------------------------------|
| 💻 Frontend  | Flutter + Dart                                    |
| 🌐 APIs      | URLHaus, urlscan.io                               |
| 🎨 Design    | Custom UI/UX from scratch (using Flutter widgets) |
| 📱 Platforms | Android (iOS support planned)                     |

------------------------------------------------------------------------

## <a href="#Lessons-Learnt" class="headerlink" title="Lessons Learnt"></a>Lessons Learnt

This project was more than just Flutter development — it taught me:

🔐 How to call and parse JSON responses from public cybersecurity APIs

🧩 How to build flexible UI layouts for error states, results, and
sharing

🧠 The importance of security-first thinking in app design

📦 How to optimize network calls and reduce response time
