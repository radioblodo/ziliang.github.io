**Problem:** [Count Unguarded Cells in the Grid](https://leetcode.com/problems/count-unguarded-cells-in-the-grid/description/)  
**Difficulty:** Medium

---

## 🧠 Approach

The `simulation` tag gives us the hint that we need to simulate the behaviour of the guard walking to the cells that he is able to reach to guard the cells. Thus, we need to have a `directions` list to simulate this behaviour of walking in the 4 directions. Then, we count the number of cells reachable by the guard and add those coordinates into a set. We don't have to worry about 2 guards walking into the same coordinate and us double or triple counting the same coordinate since items in a set are unique in Python. This way, we can take the total number of cells, which is `m * n`, then deduct away the number of original guards, number of walls as well as the peripheral cells that are reachable by the guards, we will get the number of cells that are not guarded.

---

## ⏱️ Complexity

We have a nested for-loop that loops through each guard, each of the 4 directions and a while-loop, thus the overall time complexity would be _O(m * n * number of guards)_. The space complexity should be _O(n)_ since we are creating 3 extra sets of the m \* n size at worst.

---

## ⏱️ Complexity

|          | Time                          | Space       |
| -------- | ----------------------------- | ----------- |
| Solution | _O(m * n * number of guards)_ | _O(m \* n)_ |

## ✅ Code (Python)

```python
class Solution:
    def countUnguarded(self, m: int, n: int, guards: List[List[int]], walls: List[List[int]]) -> int:
        directions = [(-1, 0), (1, 0), (0, -1), (0, 1)]

        guard_set = {(r, c) for r, c in guards}
        walls_set = {(r, c) for r, c in walls}
        guarded = set()

        for gr, gc in guard_set:
            for dr, dc in directions:
                nr = gr + dr
                nc = gc + dc
                while 0 <= nr < m and 0 <= nc < n:
                    if (nr, nc) in guard_set or (nr, nc) in walls_set:
                        break
                    guarded.add((nr, nc))
                    nr += dr
                    nc += dc

        return m * n - len(guard_set) - len(walls_set) - len(guarded)
```
