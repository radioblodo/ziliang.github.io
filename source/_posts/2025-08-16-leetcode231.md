**Problem:** [Power of Two](https://leetcode.cn/problems/power-of-two/description/?envType=daily-question&envId=2025-08-09)  
**Difficulty:** Easy

---

## 🧠 Approach

To determine if a number is a power of 2, we just need to use recursion to recursively divide n by 2. If it ever gets below 0 or if the modulo of n is ever not 0, then we can return false, else wait till 2/2 == 1, then we return true. This is very similar to the LeetCode problem 326, Power of Three. 

---

## ⏱️ Complexity

|          | Time                   | Space                  |
| -------- | ---------------------- | ---------------------- |
| Solution | _O(log<sub>2</sub> n)_ | _O(log<sub>2</sub> n)_ |

---

## ✅ Code (Java)

```java
class Solution {
    public boolean isPowerOfTwo(int n) {
        if (n == 1){return true;}
        if (n <=0 || n%2 != 0){
            return false; 
        }
        n /= 2;
        return isPowerOfTwo(n);
    }
}
```
