## ⏱️ Complexity

|          | Time               | Space  |
| -------- | ------------------ | ------ |
| Solution | _O(n<sup>2</sup>)_ | _O(n)_ |

The for-loop is _O(n)_. The while-loop cause the for-loop to be ran n times, hence _O(n<sup>2</sup>)_. We have a new string variable called `s2`.

## ✅ Code (Python)

```python
class Solution:
    def hasSameDigits(self, s: str) -> bool:
        s2 = ""

        while len(s) > 2:
            for i in range(len(s)-1):
                s2 += str((int(s[i]) + int(s[i+1])) % 10 )

            s = s2
            s2 = ""

        if s[0] == s[1]:
            return True

        return False
```
