**Problem:** [Reverse Words in a String](https://leetcode.cn/problems/reverse-words-in-a-string/description/)  
**Difficulty:** Medium
---

## 🧠 Approach

Pretty self-explanatory but a better way to split would be s.split("\\s+"). This will ensure that it will be split regardless of the number of spaces between words. 

---

## ⏱️ Complexity

|          | Time   | Space  |
| -------- | ------ | ------ |
| Solution | _O(n)_ | _O(n)_ |

---

## ✅ Code (Java)

```java
class Solution {
    public String reverseWords(String s) {
        String newString = s.strip(); 
        String[] array = newString.split(" ");
        StringBuilder sb = new StringBuilder(); 
        for (int i = array.length-1; i>=0; i--){
            if (array[i].equals("")){
                continue; 
            }
            else {
                sb.append(array[i]);
                sb.append(" ");
            }
        }
        return sb.toString().strip(); 
    }
}
```
