**Problem:** [Calculate Money in LeetCode Bank](https://leetcode.com/problems/calculate-money-in-leetcode-bank/description/)  
**Difficulty:** Easy

---

## 🧠 Approach

We simply need to simulate the rule of the game. We use `i` to simulate the number of days we have and `j` to simulate the starting amount we start at the beginning of each week. After a week has completed, we reset `j = j - i + 1`, which is 8 - 7 + 1, 9 - 7 + 1 and so on. Then, we return the `totalMoney` accumulated.

---

## ⏱️ Complexity

|          | Time   | Space  |
| -------- | ------ | ------ |
| Solution | _O(n)_ | _O(1)_ |

The inner loop runs up to 7 days while the outer loop runs ceil(n/7) so the overall time complexity is _O(7)_ \* _O(ceil(n/7))_ which is _O(n)_. We did not use any extra data structure to store anything, so the space complexity is _O(1)_.

## ✅ Code (Python)

```python
class Solution:
    def totalMoney(self, n: int) -> int:
        totalMoney = 0
        j = 1
        while n > 0:
            i = 0
            while i < 7 and i < n:
                totalMoney += j
                j += 1
                i += 1
            j -= (i-1)
            n -= i

        return totalMoney
```
