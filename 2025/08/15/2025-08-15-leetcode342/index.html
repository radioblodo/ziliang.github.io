LeetCode 342 — Power of Four

Problem: Power of Four
Difficulty: Easy

🧠 Approach

To determine whether a number is power of 4, we simply need to obtain the power (x) such that when 4 is raised to the power of which, is a whole number. To do this, the most intuitive way would be to obtain the number x and verify if x is a whole number.

Since we have broken down the requirements into 2 mini requirements:

  • Find the power x, such that when 4 is raised to the power of x, equals to n
  • Verify if x is indeed a whole number

we can work on those two requirements individually.

  1. Use Math.log(n) / Math.log(4) to find x
  2. After obtaining the value of x from (1), use the value % 1 == 0 to verify if the number is a whole number

⏱️ Complexity

Time Space
Solution O(1) O(1)

✅ Code (Java)

// Power of Four — Math.log approach
class Solution {
    public boolean isPowerOfFour(int n) {
        return (Math.log(n) / Math.log(4)) % 1 == 0; 
    }
}
