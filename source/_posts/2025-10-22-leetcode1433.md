**Problem:** [Check If a String Can Break Another String](https://leetcode.com/problems/check-if-a-string-can-break-another-string/description/)  
**Difficulty:** Medium

---

## 🧠 Approach

The main idea to tackle this problem is to use the minimally possible letter from s1 to fight against the minimally possible letter from s2. Hence we can sort the two strings and compare letter by letter. We can have 2 boolean flags, `flag1` and `flag2` that are both initially True, which means we assume that s1 can break s2 and s2 can break s1. Then as we iterate, if we find a letter from s2 that is bigger than a letter from s1, we set `flag1` to False and likewise for `flag2`. Finally, we return `flag1` or `flag2` since so long as either s1 or s2 can break the other string, we can return True.

---

## ⏱️ Complexity

|          | Time   | Space  |
| -------- | ------ | ------ |
| Solution | _O(n)_ | _O(n)_ |

We created extra copy of s1 and s2 when we use `sorted()` since it is not in-place sorting. We also have 2 for-loops which result in the final time complexity to be _O(n)_.

## ✅ Code (Python)

```python
class Solution:
    def checkIfCanBreak(self, s1: str, s2: str) -> bool:
        # Arrange both strings to be in alphabetically ascending order
        s1 = ''.join(sorted(s1))
        s2 = ''.join(sorted(s2))

        # Slice at the position where both strings have the same letters
        for i in range(len(s1)):
            if s1[i] == s2[i]:
                continue
            else:
                s1 = sorted(s1[i:])
                s2 = sorted(s2[i:])
                break

        # Iterate through the remaining string and compare character by character
        flag1 = True # assume s1 can break s2
        flag2 = True # assume s2 can break s1
        for j in range(len(s1)):
            if ord(s1[j]) < ord(s2[j]):
                flag1 = False
            elif ord(s2[j]) < ord(s1[j]):
                flag2 = False

        return flag1 or flag2
```
