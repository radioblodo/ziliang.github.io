**Problem:** [Simple Bank System](https://leetcode.com/problems/simple-bank-system/description/)  
**Difficulty:** Medium

## 🧠 Approach

To solve this question, we just need to follow the instructions given. The only part where we probably have to be a little bit more careful about is the fact that bank account number starts from 1 and the index starts from 0, we can account for that by taking `bankAccountNumber-1`. Apart from that, if you are attempting this question using other languages other than Python3, you have to use `long` instead of `int` while `int` in Python3 takes care of the integer overflow issue pretty conveniently for us.

---

## ⏱️ Complexity

The time and space complexities are both _O(1)_ since we are performing the operations without the use of loops and extra space. We are directly removing or adding the money to a specified account given an index.

## ✅ Code (Python)

```python
class Bank:

    def __init__(self, balance: List[int]):
        self.balance = balance

    def transfer(self, account1: int, account2: int, money: int) -> bool:
        if 1<=account1<=len(self.balance) and 1<=account2<=len(self.balance) and self.balance[account1-1] >= money:
            self.balance[account1-1] -= money
            self.balance[account2-1] += money
            return True

        return False

    def deposit(self, account: int, money: int) -> bool:
        if 1<=account<=len(self.balance):
            self.balance[account-1] += money
            return True

        return False

    def withdraw(self, account: int, money: int) -> bool:
        if 1<=account<=len(self.balance) and self.balance[account-1]>=money:
            self.balance[account-1] -= money
            return True

        return False
```
