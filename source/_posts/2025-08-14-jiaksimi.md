# Building the MDP Android Remote:Lessons in Embedded Systems, Bluetooth, and Team Collaboration

<div class="markdown-body">

As part of NTU’s **Multidisciplinary Design Project (MDP)** — a capstone
module for final-year Computer Science students — my team developed a
mobile-controlled robot capable of both autonomous and manual
navigation.

The project involved four core components:

- 📱 **Android App** (my main role)
- 🍓 **Raspberry Pi** (Bluetooth receiver + logic relay)
- 🧠 **Pathfinding Algorithm**
- 🔩 **STM32 Microcontroller** (motor control + sensors)

Although I was responsible for the Android app, I was actively involved
in:

- 🛠️ Raspberry Pi development
- 🧪 STM32 signal testing and hardware debugging
- 👥 Team integration and testing sessions

------------------------------------------------------------------------

## <a href="#🎯-Project-Goals" class="headerlink"
title="🎯 Project Goals"></a>🎯 Project Goals

The Android app — developed in **Kotlin** using **Jetpack Compose** —
aimed to:

- Establish a **Bluetooth connection** to the Raspberry Pi
- Allow **manual control** of the robot with directional buttons
- Display **live feedback** from the robot (e.g. status updates,
  position)
- Log the robot’s path for visual tracking and testing

------------------------------------------------------------------------

## <a href="#⚙️-Key-Technical-Highlights" class="headerlink"
title="⚙️ Key Technical Highlights"></a>⚙️ Key Technical Highlights

- Built a clean and responsive UI from scratch using **Jetpack Compose**
- Implemented **Bluetooth socket communication**, managing input/output
  streams efficiently
- Ensured smooth two-way communication for **manual overrides**,
  **status polling**, and **sensor relay**
- Added **live logs** and **status tracking** features for debugging and
  verification

## <a href="#🧠-What-I-Learned" class="headerlink"
title="🧠 What I Learned"></a>🧠 What I Learned

- Deepened my knowledge of **Kotlin**, Android lifecycle, and UI
  architecture
- Learned to work with **hardware protocols**, especially integrating
  with the Raspberry Pi and STM32 via Bluetooth and serial
- Gained confidence in debugging issues across multiple platforms (e.g.
  Android logs, RPi console, STM32 UART output)
- Realized the importance of **cross-functional collaboration** in
  real-world systems — especially in synchronizing embedded, mobile, and
  algorithm teams
