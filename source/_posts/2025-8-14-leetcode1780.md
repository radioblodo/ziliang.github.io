**Problem:** [Check if Number is a Sum of Powers of Three](https://leetcode.cn/problems/check-if-number-is-a-sum-of-powers-of-three/description/?envType=daily-question&envId=2025-08-14)  
**Difficulty:** Medium

---

## 🧠 Approach

To determine whether a number is a sum of the powers of three, we can first convert it to base 3. In base 3 format, we can check if it only contains 0 and 1. If it does, then it is a number that is a sum of the powers of 3, else it is not. The reason behind this is because, for each unique power, 0 ~ +ve infinity, the occurrence of 3^unique power is 1 or 0, it is either part of the sum or not part of the sum, it cannot ever be a case where 18(base 10) = 200 (base 3) = 3^2 + 3^2, which makes it no longer distinct (which is what the question requires).

In steps, we simply have to:

1. Get the base 3 string of the number that is passed in
2. Check if the base 3 string only contains strictly 1 and 0s

---

## ⏱️ Complexity

|          | Time      | Space     |
| -------- | --------- | --------- |
| Solution | O(log(n)) | O(log(n)) |

---

## ✅ Code (Java)

```java
class Solution {
    public boolean checkPowersOfThree(int n) {
        // Convert the given number to base3 string
        String base3String = Integer.toString(n, 3);

        /*
        - .matches() checks the entire string, not the substring, which would result in error because we want the entire string to only contain 0 and 1 only
        - [01] means either 0 or 1
        - + means there could be more than 1 occurrence of 0 and 1
        */
        // Check if it's only 1 and 0 inside
        return base3String.matches("[01]+");
    }
}
```
