**Problem:** [Find the Student that will Replace the Chalk](https://leetcode.com/problems/find-the-student-that-will-replace-the-chalk/)  
**Difficulty:** Medium

---

## 🧠 Approach

We just need to find the number of complete rounds the chalk can go round from head to toe. Then, with the remainder chalk, we start distributing from the first student at index 0 again, until we find the student at index i that does not have enough chalk to go round, we return i.

---

## ⏱️ Complexity

|          | Time   | Space  |
| -------- | ------ | ------ |
| Solution | _O(n)_ | _O(1)_ |

## ✅ Code (Python)

```python
class Solution:
    def chalkReplacer(self, chalk: List[int], k: int) -> int:
        if len(chalk) == 1:
            return 0

        # Use modulo to find the remainder portion of chalk available
        remainder = k % sum(chalk)

        # Use a while-loop to find the first student that needs a replacement
        i = 0
        while remainder > 0:
            if remainder >= chalk[i]:
                remainder -= chalk[i]
                i += 1
            else:
                return i

        return i
```
