**Problem:** [Sum of Left Leaves](https://leetcode.com/problems/sum-of-left-leaves/description/)  
**Difficulty:** Easy

---

## 🧠 Approach

This is a simple one pass solution. No extra space is required. Something I learned from this problem is that in order for the inner function to be able to modify the value of a variable that was defined in the outer function, there needs to be a `nonlocal variable_name` declaration in the inner function, else the inner function only has the read access but not write access.

---

## ⏱️ Complexity

|          | Time   | Space  |
| -------- | ------ | ------ |
| Solution | _O(n)_ | _O(1)_ |

The time complexity of Depth-First Search (DFS) on a binary tree is O(n), where n is the number of nodes in the tree. O(1) for space since no extra space is required.

## ✅ Code (Python)

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def sumOfLeftLeaves(self, root: Optional[TreeNode]) -> int:
        res = 0
        def dfs(root: Optional[TreeNode]):
            nonlocal res
            if root == None:
                return

            if root.left and root.left.left == None and root.left.right == None:
                res += root.left.val
            dfs(root.left)
            dfs(root.right)

        dfs(root)
        return res

```
