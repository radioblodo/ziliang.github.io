**Problem:** [Buy Two Chocolates](https://leetcode.com/problems/buy-two-chocolates/description/)  
**Difficulty:** Easy

---

## 🧠 Approach

This is a simple solution once we realise what we are doing. Essentially, imagine you have `x` amount of money and you walk into a candy shop. Your goal is to buy 2 choclate bars, regardless of the flavor or the texture. Naturally, you would want to go to the section that has the cheapest chocolate bars. Hence, we sort the prices in ascending order. If our money >= prices[0] + prices[1], we can afford to buy the 2 cheapest chocolate bars, else, if we cannot even afford to buy these 2, there really isn't a point for us to check prices[1] + prices[2] anymore.

---

## ⏱️ Complexity

|          | Time       | Space  |
| -------- | ---------- | ------ |
| Solution | _O(nlogn)_ | _O(1)_ |

Here we are using Timsort, a sorting algorithm written by guess who? Tim Peters of course. The worst case time complexity would be _O(nlogn)_. _O(1)_ for space since no extra space is required.

## ✅ Code (Python)

```python
class Solution:
    def buyChoco(self, prices: List[int], money: int) -> int:
        # Sort the given prices array in ascending order in-place
        prices.sort()

        # Check if money >= prices[0] + prices[1]
        return money - prices[0] - prices[1] if (prices[0] + prices[1]) <= money else money
```
