**Problem:** [H-Index](https://leetcode.cn/problems/h-index/description/?envType=study-plan-v2&envId=top-interview-150)  
**Difficulty:** Medium

---

## 🧠 Approach

The key to solving this problem is to understand the definition of h-index. 
h-index = The h-index is the largest integer h such that at least h publications each have ≥ h citations.

Knowing this, we just have to sort the numbers in ascending order. Then for each citation, we find the min(citation count, number of papers with >= citation count). Return the max at the end. 

---

## ⏱️ Complexity

|          | Time                   | Space                  |
| -------- | ---------------------- | ---------------------- |
| Solution | _O(nlogn)_ | _O(n)_ |

---

## ✅ Code (Java)

```java
class Solution {
    public int hIndex(int[] citations) {
        Arrays.sort(citations);
        List<Integer> hIndexes = new ArrayList<>(); 
        for (int i = 0; i < citations.length; i++){
            hIndexes.add(Math.min(citations[i],citations.length - i));
        }
        Collections.sort(hIndexes);
        return hIndexes.get(hIndexes.size()-1);
    }
}
```
