**Problem:** [Make Array Elements Equal to Zero](https://leetcode.com/problems/make-array-elements-equal-to-zero/description/)  
**Difficulty:** Easy

---

## 🧠 Approach

The pattern is not so straightforward but the key idea is that we can only clear the left half if there is equal or 1 less `1` on the right and vice versa. So if the left half contains the equal sum as the right half, you have two ways to make all elements 0 because you could either go left first or go right first. However, in the case where the left half and right half differ by only 1, you only have 1 way because you have to start with the portion that has 1 more, thus you add 1 to the result.

---

## ⏱️ Complexity

We just need to iterate through the given `nums` array once.

---

## ⏱️ Complexity

|          | Time   | Space  |
| -------- | ------ | ------ |
| Solution | _O(n)_ | _O(1)_ |

## ✅ Code (Python)

```python
class Solution:
    def countValidSelections(self, nums: List[int]) -> int:
        left = 0
        res = 0
        total = sum(nums)

        for num in nums:
            if num:
                left += num
            else:
                if left * 2 == total:
                    res += 2
                elif abs(total - 2 * left) == 1:
                    res += 1

        return res
```
